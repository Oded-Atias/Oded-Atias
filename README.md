### 🧑‍💻 About Me

> I'm a **Software Engineer** who loves turning ideas into fast, polished web products.
> I live somewhere between a clean React component and a well-designed API — and I care about the details in both.

- 🔭 &nbsp;I build **full-stack applications** end-to-end with **React**, **React Native**, and **NestJS / Node.js**

- 🎨 &nbsp;I love crafting **smooth, pixel-perfect UIs** from Figma & Zeplin designs
